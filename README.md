# Gerador de Tabuada Dinâmico 🔢

Este é um script Python simples e eficiente projetado para gerar a tabuada de qualquer número inteiro escolhido pelo usuário. É um excelente exemplo de como automatizar tarefas repetitivas usando lógica de programação.

## ✨ Funcionalidades

- **Entrada Personalizada:** O usuário define qual tabuada deseja visualizar.
- **Iteração Automática:** Utiliza a estrutura de repetição `for` para processar os cálculos de 1 a 10 instantaneamente.
- **Saída Formatada:** Exibe os resultados de forma clara e organizada no terminal utilizando *f-strings*.

## 🧠 Lógica Implementada

O coração deste projeto é a função `range(1, 11)`, que gera uma sequência numérica começando em 1 e parando antes de chegar ao 11. Isso garante que a tabuada cubra exatamente os multiplicadores de 1 a 10.

## 🚀 Como Executar

1. Certifique-se de ter o Python instalado.
2. Salve o código em um arquivo chamado `tabuada.py`.
3. No terminal, execute:
   ```bash
   python tabuada.py
